# Potato-Injector
my own fix of potato injector to the actual verison of cs2, please star this repo if you like it
lightweight injector for valve games with improved vac bypass, especially for vac3 and cs2

## How to start
#### download the latest release tag from releases 
start the program
click add
select your .dll file
select the process you want to inject file
select one of injecting methods from settings
click inject
